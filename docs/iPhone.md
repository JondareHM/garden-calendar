# Abonner fra iPhone Kalender

Brug et abonnement, så fremtidige ændringer fra GitHub Actions bliver hentet automatisk.

1. Åbn **Indstillinger**.
2. Gå til **Kalender**.
3. Gå til **Konti**.
4. Vælg **Tilføj konto**.
5. Vælg **Anden**.
6. Vælg **Tilføj abonnementskalender**.
7. Indsæt URL'en til `calendar/have.ics`, for eksempel:

   `https://JondareHM.github.io/garden-calendar/calendar/have.ics`

8. Tryk **Næste** og gem.

iPhone opdaterer abonnementskalendere automatisk, men ikke nødvendigvis øjeblikkeligt. Brug abonnement i stedet for at importere `.ics`-filen manuelt; import giver ikke fremtidige opdateringer.
